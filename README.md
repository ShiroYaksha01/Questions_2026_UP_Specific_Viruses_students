# Virology QCM Exam Review (UP 2026)

Interactive Multiple Choice Question (QCM) exam review website containing all **241 official exam questions** across 11 virology lectures from `Questions_sending_2026_UP_Specific_Viruses_students.pdf`.

Every single answer in this application is **100% synchronized with the yellow highlight annotations** from the original lecture PDF.

---

## 🪟 1. How to Use on Windows (No Installation Required)

> **For Students:** You do **NOT** need Python, Node.js, an IDE, a compiler, or any command line tools.

1. Locate the file **[`index.html`](index.html)** in Windows File Explorer.
2. **Double-click** `index.html`.
3. It opens immediately in your web browser (**Microsoft Edge**, **Google Chrome**, **Firefox**, or **Brave**) and works completely offline!

---

## 🎲 2. How Randomization Works

The application provides real-time dual randomization:
- **🔀 Randomize Questions:** Shuffles the presentation order of questions so you don't memorize question positions.
- **🔀 Randomize Answers (A, B, C, D):** Shuffles the choices inside each question so you must read and recognize the correct medical concept rather than memorizing letter positions.
- **🎲 Shuffle All:** Click the top-right button anytime to instantly reshuffle both questions and answer choices with a fresh layout.

## 🚀 3. How to Host on Vercel (Free & Instant)

This project is fully configured for zero-setup static deployment on **Vercel** via [`vercel.json`](vercel.json).

### Method A: Via Vercel Web Dashboard & GitHub (Easiest)
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New..."** → **"Project"**.
4. Import your GitHub repository.
5. Keep all default settings (Framework Preset: *Other*) and click **"Deploy"**.
6. Your review site is live worldwide with a free `.vercel.app` domain in ~10 seconds!

### Method B: Via Vercel CLI (Command Line)
If you have Node.js installed, open terminal/command prompt in this folder and run:
```bash
npx vercel
```
Follow the 3 quick prompts to deploy immediately.

## 📚 4. Features & Content Breakdown

- **11 Virology Lectures Included:**
  1. Human Immunodeficiency Virus (HIV) — 20 Questions
  2. Orthomyxoviridae - Influenza virus — 30 Questions
  3. Arboviruses (Dengue, Zika, JEV, Chikungunya) — 32 Questions
  4. Ebola virus (Filoviridae) — 17 Questions
  5. Coronaviruses (SARS, MERS, COVID-19) — 30 Questions
  6. Poliovirus (Enterovirus C) — 20 Questions
  7. Lyssavirus & Rabies — 17 Questions
  8. Papillomaviridae (HPV) — 17 Questions
  9. Poxvirus (Smallpox & Mpox) — 15 Questions
  10. Herpes viruses (HSV, VZV, EBV, CMV) — 20 Questions
  11. Viral Hepatitis (HAV, HBV, HCV, HDV, HEV) — 23 Questions
- **Instant Medical Feedback:** Option turns green when correct, red when wrong, with the official highlighted answer, rationale, and exam takeaway.
- **Question Palette:** Jump to any question and monitor answered vs. unanswered status.
- **Question Bookmarking (⭐):** Star difficult questions to review them exclusively using the "Starred Only" toggle.
- **Keyboard Shortcuts:**
  - `1`, `2`, `3`, `4` or `A`, `B`, `C`, `D` — Select options
  - `←` / `→` — Navigate between questions
  - `S` — Star/Bookmark question
- **🌙 Dark / Light Mode:** Switch between clean daytime reading and dark study mode.
